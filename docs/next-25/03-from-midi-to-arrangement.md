# Turn a MIDI sketch into an arrangement

A four-bar idea becomes useful when it can change without losing its identity. Keep the main contour, then vary density, register, duration or the moment an answer arrives. A small change can create a verse-to-chorus relationship without requiring a new melody every eight bars.

Each study in this release includes a combined arrangement and separate roles. Choose one route when opening it: the combined file is useful for hearing the whole sketch, while the separate parts make it easier to replace instruments or rearrange the section. Stacking both versions doubles the same notes.

One practical starting sequence:

1. Listen to the combined study, then mark the phrase that stands out.
2. Open the separate melody and bass parts in a new session.
3. Remove half the notes for a quieter section, then restore or alter them for the return.
4. Change patches, harmony, and structure to fit the song.

The included synthesizer previews demonstrate timing and note choices. They are not a representation of how a finished production must sound.
